# BRL Perio Chart

BRL 중재연구용 치주 검사 전자 차트입니다. 갤럭시 탭 / 아이패드 브라우저에서 직접 입력합니다.

## 사용 방법

1. GitHub Pages 주소를 태블릿 브라우저(Safari/Chrome)로 엽니다.
2. **시트 연동 설정** 버튼을 눌러 Google Apps Script 웹앱 URL을 입력하고 저장합니다. (기기당 1회)
3. 홈 화면에 추가하면 앱처럼 전체 화면으로 사용할 수 있습니다.
   - iPad: 공유 → 홈 화면에 추가
   - Galaxy Tab: 메뉴(⋮) → 홈 화면에 추가

## 데이터 흐름

- 저장 시 회차별 탭(Baseline / Mid-point / End-point)으로 공유 구글 시트에 자동 누적됩니다.
- 기기 로컬(localStorage)에도 함께 저장되어 네트워크가 끊겨도 유실되지 않습니다.
- 엑셀 내보내기로 기기에 xlsx 파일을 받을 수 있습니다.

## 보안 및 개인정보

- 이 저장소에는 **환자 데이터가 전혀 포함되지 않습니다.** 빈 입력 도구만 공개됩니다.
- Apps Script 웹앱 URL과 보안키는 코드에 포함하지 않고, 각 기기의 설정 화면에서 입력합니다.
- `AppsScript_Code.gs`는 수신용 스크립트 템플릿이며, 시트 ID는 각자 배포 시 입력합니다.
